# 혜택 레이더

근처 매장에 도착하면 잊고 있던 멤버십·쿠폰을 알려주는 스마트 지갑 도우미 (웹앱/PWA 데모).

## 기능

| 화면 | 내용 |
|---|---|
| 내 지갑 | 멤버십·쿠폰 등록 (브랜드 프리셋 18개 / 직접 입력, 만료일, 바코드 메모) |
| 레이더 | 지도 + 실제 GPS 또는 시뮬레이션, 반경 600m 안의 내 혜택 매장 (OpenStreetMap) |
| 도착 알림 | 매장 60m 안에서 머무르면(GPS 15초·정지 상태 / 시뮬레이션 3초) 하단 시트 + 진동. 다른 탭·앱을 보고 있을 때는 시스템 알림 |
| AI 추천 | Gemini가 만료 임박 쿠폰·멤버십 조합을 고려한 안내 문구 생성 (실패 시 기본 문구) |
| 바코드 보기 | 쿠폰·멤버십을 누르면 계산대에서 찍을 수 있는 바코드 전체 화면 (화면 꺼짐 방지) + 사용 완료 기록 |
| 캡처 자동 등록 | 기프티콘·쿠폰 캡처를 올리면 Gemini가 브랜드·내용·만료일·바코드 번호를 채움 |
| 혜택(이벤트) | Gemini + Google 검색으로 내 지갑·인기 브랜드의 진행 중 행사를 출처와 함께 모음 (키 없으면 예시 데이터) |
| 리포트 | 이번 달 아낀 금액, 브랜드별 절약, 놓친 쿠폰, 사용 기록 / 지갑 상단에 이번 주 만료 브리핑 |
| 설정 | Gemini API 키·모델, 연결 테스트, 시연 도구(알림 기록·샘플 초기화) |

## 실행

```bash
pnpm install
pnpm dev          # PC: http://localhost:5173
pnpm phone        # 폰: 같은 Wi-Fi에서 터미널에 표시된 Network URL(https://…) 접속
pnpm build        # dist/ 정적 파일 (서버 불필요)
```

### 폰에서 실행하는 두 가지 방법

| 방법 | GPS | 시스템 알림 · 홈 화면 설치 |
|---|---|---|
| `pnpm phone` (자체 서명 HTTPS) | 경고 → **고급 → 계속** 후 동작 | 동작하지 않음 (인증서 오류 상태에서는 서비스워커 등록 불가) |
| `dist/`를 정적 호스팅에 배포 (Netlify, Vercel, Cloudflare Pages 등) 또는 터널(cloudflared, ngrok) | 동작 | 동작 (Chrome 메뉴 → 홈 화면에 추가) |

- 매장 검색(Overpass)과 Gemini 호출은 모두 브라우저에서 직접 하므로 정적 배포만으로 충분합니다.
- 홈 화면 앱으로 처음 열면 위치·알림 권한을 다시 묻습니다. 시연 전에 미리 허용해 두세요.
- Gemini: 설정 탭에 API 키 입력 → 연결 테스트. 키는 해당 기기 브라우저에만 저장됩니다. 시연용 키는 Google 콘솔에서 사용량 제한을 걸어 두세요.

## 시연 시나리오 (영상용, 약 1분)

1. **설정** → 알림 기록 초기화, (필요 시) 샘플로 초기화
2. **내 지갑** → 스타벅스 쿠폰(D-3), CU 멤버십, 올리브영 쿠폰 확인 → 새 쿠폰 1개 등록
3. **레이더** → 시뮬레이션 → 근처 혜택 매장 목록 확인
4. 스타벅스 **걸어가기** → 반경 진입 시 "도착" 표시 → 3초 후 알림 시트 (Gemini 추천 문구로 교체)
   → 쿠폰 카드 탭 → 바코드 화면 → 금액 입력 후 **사용 완료** → 리포트에서 아낀 금액 확인
5. **지갑 → +** → "캡처로 자동 채우기"로 기프티콘 등록, **혜택** 탭에서 근처·내 브랜드 행사 확인
6. 실제 GPS로 걸어서 시연할 경우: 매장 앞에서 15초 정도 멈춰 서기. 지도에 없는 매장은 레이더 하단에서 현재 위치에 등록

시연 전 체크: 시연 장소에서 앱을 한 번 열어 매장 검색 결과를 캐시해 두기(검색 서버가 느릴 때 대비), Gemini 연결 테스트로 응답 확인.

## 한계 (웹앱)

- 화면이 켜져 있고 앱이 열려 있을 때만 위치를 확인합니다. 백그라운드 지오펜싱은 네이티브 앱(Android Geofencing API)이 필요합니다.
- 매장 데이터는 OpenStreetMap Overpass 기준이라 누락이 있을 수 있고, 서버가 느릴 때는 마지막 결과를 보여 줍니다.
- Samsung Wallet과 직접 연동하지 않습니다. 실서비스에서는 Wallet 파트너 API·딥링크 연동과 위치정보법상 위치기반서비스사업자 신고가 필요합니다.
